# 流式几何引擎(G 线,2026-09-20 设计)

起因:用户 09-20 报三件事 —— 发送后屏上有两处「在等」的动画;头部那道消失时布局上下变化;思考段想完自动收起,正在读的人被打断。随后提出要一个排版 / 渲染引擎,五条要求:

1. 引入块级处理:后面的块折叠或收缩,不影响前面块的位置;
2. 块可扩展(工具调用等),且遵循自动跟随的规则;
3. 允许流式时不展开,用动画表示它正在生成(例如思考段);
4. 流式渲染是增量渲染,不对历史做完整重渲;
5. 流式结束时不错位、不重排;元素在流式中只要落在屏幕上,位置就确定了。

R 线(`stream-render-2026-09.md`)管的是「**画什么**」:内容只增不换、块身份稳定、DOM 不重挂。「**画在哪**」一直没有负责方,今天由五个互不认识的补丁各管一角:`content/follow.ts`(跟底)、`content/seat.ts`(发送后的座位垫块)、`content/tail-snap.ts`(尾部亚像素对齐)、`content/fold-intent.ts`(折叠时钉视口)、`content/expand-intent.ts`(点开时别贴底)。每个补丁治好自己那一种跳法,下一种还会来。G 线立的是几何那一半的宪法,并指定唯一的负责方。

## 1. 五条几何不变式(宪法)

**G1 · 后块变矮,屏上其余不动。** 文档流里后块收缩本来就不改前块的文档坐标;让前面跳的是贴底时页面总高变小、浏览器钳 `scrollTop`。所以:**一轮之内页面总高在任何一次排版里都不许变小**。手段是卷尾垫块(§3.3):任何块缩掉的高度记进垫块。

**G2 · 收缩先申请、后执行。** 今天的病根是顺序:块自己先缩,引擎事后补救,而钳位发生在中间那次排版里。规矩:块向引擎申请「我要缩」→ 引擎从几何账本读出缩之前的高度、先把垫块加长 → 块再缩。「量改后多高」这类会逼出排版的读取,只许引擎在垫块到位之后做。

**G3 · 块有直播形,自动收缩不存在。** 每种块声明流式期间的形:`grow`(跟着内容长,如正文)/ `fixed`(高度恒定、里面在动,如思考段)/ `reserve`(先占形、内容后到,如图片、公式)。块的高度在流式期间只增不减;会变矮的只有一种原因 —— 用户自己点的。

**G4 · 落定那一帧几何上什么都不发生。** 收尾只许换透明度、颜色、停动画,不许换高度。只在流式期存在的东西必须住进**槽位**:从头到尾都占着的固定格子,内容只换 `opacity`。

**G5 · 上屏即定位。** 定的是相对这一轮起点的**文档坐标**。屏幕上只允许一种运动:贴底跟随时整体匀速上移。此外任何东西都不许动。

推论五条(引擎必须回答):

- `scrollTop` **只许一个写者**(锚定器,§3.2);块不许碰滚动,只报几何变化。
- **用户主动展开 / 收起**:被点的那一块顶边不动,只有它下面的让位。
- **事后才出现的行**(上下文更新行、收场通知、来源脚注):要么进槽位,要么只许出现在尾部。
- **整体重排**(拖窗口、开关侧栏):以视口里第一块的顶为读者锚点恢复位置。
- **执法**:真机门 `gate:stream-geometry`(必须含**短会话**场景)+ dev 运行时断言「上过屏的活动块高度不许变小,除非原因是用户」。

## 3. 结构(都是现有件的收编)

### 3.1 一轮回复的排版

```
[用户气泡]
[上下文更新行]          ← 事后行,只在这一轮开张时出现一次
[活消息 article]
   [块 … 块(frozen)] [活动块(live)]
   [动作格]             ← 常驻,流式中 opacity 0 + inert
[卷尾垫块]              ← 座位 + 吸收的回缩
[尾槽]                  ← 整列常驻的一格:等待扫光 / 光标 + 读数 + 停止;不在跑时透明
```

只有**槽位**和**块**,之间不许条件渲染别的东西。

### 3.2 锚定器(`ViewportAnchor`,P2)

收编 `follow` / `seat` / `tail-snap` / `fold-intent` / `expand-intent`。所有几何变化报给它:

```ts
interface GeometryChange {
  blockId: string
  deltaH: number
  cause: 'tail-growth' | 'user-toggle' | 'late-insert' | 'settle'
}
```

裁决:视口下方 → 不管;视口上方 → 补偿 `scrollTop`;视口内 `tail-growth` 且贴底 → 跟随;视口内 `user-toggle` → 钉住被点那一块的顶;其余 → 违例(dev 报错)。

### 3.3 卷尾垫块(P2)

现有座位垫块的升级:`height = max(座位所需, 本轮已吸收的回缩)`。释放时机:用户滚动、下一次发送。

### 3.4 段注册表与几何契约(P3)

正文块已经是「自述 + 注册表」(`blocks/registry.ts`,五问流式契约里已有 `geometry: 'flow' | 'reserve'`)。段这一层还是枚举:`SegmentView.tsx` 的 `switch(kind)` 与 `assemble/index.ts` 的 `switch`。按仓根「加功能不许改骨架」法,两处都改成读表:

```ts
interface SegmentDef<M> {
  kind: string
  produce(part: ProjectedPart, prev?: M): M
  View: ComponentType<{ model: M; ctx: BlockCtx }>
  stream: BlockStreamContract          // 现有五问,原样
  geometry: {
    liveForm: 'grow' | 'fixed' | 'reserve'
    settle: 'same-height'              // 只有这一个合法答案,写出来是为了必答
    shrink: 'never' | 'user-only'      // 没有「自动」这一档
  }
}
```

**陌生能力演练**:加一个没想过的块(AI 生成的 HTML 预览)。要改的 = 它自己的模块(`produce` + `View` + 契约,`liveForm: 'reserve'`)+ 一行注册。跟随、垫块、落定不跳都不用它操心。前提是两个 `switch` 真的删了。

### 3.5 冻结线与几何账本(P4)

块只有 `live → frozen` 两态,单向。冻结之后不再量高、不再重渲;高度记进账本,交给 `content-visibility` 当占位高。三份 `HeightBook`(`ui/flip-height` 通用 / `tools/card-heights` / `thought-heights`)合成一份,按块 id 记 {高度, 首次上屏时刻, 是否冻结},同时喂锚定器、占位高、dev 断言。每帧工作量只跟活动块有关,由 `gate:perf` 守。

## 7. P1 施工账(2026-09-20)

止血三件与那道几何门都落了地。**与 §5 设计不一样的地方以这一节为准**,逐条写明为什么。

### 7.1 与设计不一样的六处

1. **座位必须与内容**同帧**改,不是「量在这一帧、写在下一帧」**(设计里没有这一条,
   是这道门第一趟真机挖出来的)。座位从前走 `FrameCoalescer` 下一帧写,于是每来一段
   delta:第 n 帧内容 +Δ、座位没动 → `scrollHeight` +Δ;第 n+1 帧座位 −Δ → 回来。
   **屏幕上从前看不出来** —— 读数行那时住在正文**里面**,跟着内容一起往下走,那一格差
   被它自己的位移盖住了(正是 §0 的病 ④)。P1 把读数与光标搬到**座位之后**,这一格差
   当场显形:首字那一帧尾槽被推下 **29–92px**(= 第一块内容的高),整轮 `scrollHeight`
   回缩 **3–15 次**。
   一帧之内两头不能兼得(不动视口 → 座位**下面**的跳;贴底 → 座位**上面**的跳,自己那条
   气泡当场违反 `send-flow` 规矩 ②),唯一的出路是**让那一格差不存在**。所以
   `ChatStream` 多了一只 layout effect:座位在场且还没吃光时,在 React 提交之后、绘制
   之前同步 `readSeat` + `writeSeat`。它是 §1 的 G2「收缩先申请、后执行」在 P1 能做到的
   那一半(完整的两段式归 P2 的锚定器)。
   三道闸让它不重演 09-10 那只「每次提交都 `stick()`」的 834ms:座位不在场 / 座位已吃光 /
   正在滑(发送与重试的插值),任一命中立刻返回。**反证**见 7.3 第一行。
2. **等待那道折痕不是「新画一件」,是 `WaitingSeam` 换了住处**。§5.2 写的是「复用折痕
   基座的 `SeamLine`」,实现上直接消费了 `content/seam/WaitingSeam`(它的自述本来就是
   「一道没有标签的、在扫的折痕」),只删掉它那句 `min-height`(高度归宿主那一格 token)
   并改写文件头。理由是仓根第一条:**组件化而不是创建新的组件**;任务单里那句
   「确认零消费者后删」是个条件句,而它今天有一个消费者。
3. **尾槽里的三张脸,空着时那两张不挂载**。§5.2 说「三张脸同格只换 opacity」——
   几何上那句话由 token `--tail-slot-h` 兑现(与此刻是哪张脸无关),而**在跑**时两张脸
   确实同格、交叉淡入、暗的那张 `inert`;**不在跑**时两张都不挂载。因为那道扫光与那枚
   光标是两段 `infinite` 动画,一片会话叶一份,而一台上可以并排开好几片 —— 空着时挂着
   是白烧,而几何一格都不多给。
4. **收起态那一行的高由 `block-size` 钉死,不靠两态恰好一样高**。§5.1 只说「两态高度
   逐像素相同」;实现上不敢把它交给内容(流式那一截右端对齐、落定那一截左起 + 省略号),
   所以 `.thoughtPreview` 直接 `block-size: calc(var(--fs-meta) * 1.6)`。
   右端对齐那一手也比设计多一句:`justify-content: flex-end` **加** `flex: none`
   —— 只写 `margin-inline-start: auto` 不成立(自动外边距只吃**剩余**空间,而这里
   剩余是负的,它当场解析成 0)。
