名词对照
  1. 全局(蓝角标)= 跨工作区,换工作区它跟着人走;本区 = 只属于这个工作区。
  2. 单例 = 同一样东西这个工作区里只一份,再点是把它叫到前面,不是再开一份。
  3. 多开 = 目录 / 文件 / 改动按「哪个目录、哪个文件」各一份;同一个目录还是只一份。
  4. 跟随 = 切会话时,壳去找「根等于新会话 workdir」的那一份目录 / 改动面板。
