# 音乐面 · 整面布局（v7）

2026-09-18 立。样例：<https://claude.ai/artifact/SnEEqJjPNdgatopJeFp3b9>（唱机音乐 App，用户看过并认可的那一版）。唱机场景与黑豆见 `docs/design/pet-system-2026-09.md` §8。

## 0. 为什么改

M1 把节目单直铺在唱机下面。用户原话：「你这个歌词我以为是歌曲列表呢。谁家歌曲列表直接往下铺一排啊。」音乐软件的做法是：歌单藏在一个按钮后面，主界面留给正在放的这一首。宠物 P1 只换了唱机那一块，整面还是老样子，所以这一单把整面补齐。

## 1. 现形

```
┌─────────────────────────────────────────┐
│ 提示行（后端没配好 / 出错，有才画）        │
│ 电台条 StationStrip                      │
├──────────────────┬──────────────────────┤
│ 唱机场景          │ 歌词（≥900 才有这一栏） │
│ 歌名 · 歌手       │                      │
│ 歌条 Transport    │                      │
└──────────────────┴──────────────────────┘
```

- **窄 / 中（< 900）**：一栏。唱机场景 → 歌名 → 歌条。歌词不在主界面上，点歌条上的「歌词」进歌词页（唱机场景整块换成歌词，页头一颗小碟点回来）。
- **宽（≥ 900）**：两栏。左边唱机 + 歌名 + 歌条，右边常驻滚动歌词，没有歌词按钮。
- **播放列表**：任何宽度都不铺在页面上。歌条上一颗「播放列表」钮打开抽屉：≥560 从右侧滑出（宽 360–400、通高），< 560 从底部升起（高 82%）。内容就是今天的 `ProgrammeSheet`（正在播放 / 接下来 / 播放历史三段、拖拽换序、右键菜单）。点遮罩、按 Esc、按 ✕ 都关，焦点回到那颗钮。

## 2. 歌条 Transport 的按钮

一行，从左到右：♥ · ⏮ · ⏯ · ⏭ · 歌词（仅 < 900）· 播放列表 · 音量。进度条在下面一行，与唱臂共用同一个位置读数。

## 3. 三张状态表

### 3.1 生命周期

| 事件 | 面做什么 |
| --- | --- |
| 挂载 | 按当前宽度定一栏 / 两栏；抽屉关着；歌词页不在 |
| 宽度跨过 900 | 两栏 ↔ 一栏。从两栏变一栏时歌词**不**自动进歌词页（回到唱机）；从一栏变两栏时，若正停在歌词页则退回唱机并在右栏显示歌词 |
| 打开抽屉 | 抽屉滑出，焦点落到抽屉里第一个可聚焦元素；主界面不动、照常播 |
| 关抽屉 | 焦点回到「播放列表」钮 |
| 换歌 | 抽屉开着不关；歌词页开着不退 |
| 电台关台 / 没歌 | 歌词页退回唱机；抽屉留着（里面是空态） |
| 卸载 | 抽屉与歌词页状态不落盘（下次开面板从唱机开始） |

### 3.2 UI 生命状态

| 状态 | 主界面 | 抽屉 |
| --- | --- | --- |
| 首载 | 唱机场景照画（素面唱片），歌名与歌条不画 | 里面三段各自不画 |
| 没歌 | 唱机空态（见 §8 空态），歌名位置一句「播放器没在跑」，歌条不画 | 「接下来」为空时那一段不画 |
| 有歌 | 歌名 · 歌手 + 歌条 | 正在播放行高亮 + 均衡器条 |
| 歌词读不到 | 歌词区一句「这首没有歌词」（≥900 右栏 / 歌词页同一句） | — |
| 出错 | 顶上提示行一句原话，其余照常 | — |
| 超量 | 歌名过长单行截断；节目单封顶 `PROGRAMME_LIMIT` 行 | 抽屉内滚动 |

### 3.3 交互

| 动作 | 结果 | 发什么 |
| --- | --- | --- |
| 点「播放列表」 | 开 / 关抽屉（`aria-expanded`） | 不发 |
| 点「歌词」（< 900） | 进 / 出歌词页 | 不发 |
| 点歌词页页头小碟 | 回唱机 | 不发 |
| 点歌词某一句 | 从这句放 | `seek` |
| 抽屉里的行为 | 与今天的 `ProgrammeSheet` 一字不改 | 原样 |
| Esc | 有抽屉先关抽屉；没抽屉在歌词页则回唱机；都没有不拦 | 不发 |

## 4. 不做

- 不做 tab（用户否过两次）。
- 不在界面上写解释性的字（「正在放」这类），状态由画面自己说。
- 不动唱机场景内部与黑豆（那是宠物 P1 / P3 的地盘）。

## 5. 门

- 壳 vitest：抽屉开关与焦点归还、Esc 两级、≥900 两栏时没有歌词钮、跨 900 的两条规矩、歌词页进出。
- `npm run typecheck`、eslint、`ui:consume`、`motion-gate`、`squeeze-gate`。
- music-lab 截图：300 / 360 / 620 / 900 / 1040 / 1280 六档 × （有歌 / 没歌 / 抽屉开 / 歌词页）。
