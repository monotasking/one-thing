# 发送 · 等待 · 生成 · 收尾 · 重试 —— 一条座位(2026-09-15)

正本。样例页 `docs/send-flow-proposal-2026-09-14.html`(可交互,页内每帧量位移),用户 09-15 拍「可以实现了」。

## 0. 起因与推翻的拍板

用户 09-14:「发送消息要非常自然;发送之后自动留出足够的空白;后续 waiting / generating 都非常连贯;流式结束后也要连贯;重试的动画、交互。」

这推翻 `docs/workbench-2026-09.md` 拍点 ⑤(09-04:发送后自己那条**落底 + 跟随**,置顶留账不做)。从今天起:**发送后自己那条置顶,下面整个视口留给回复**。

今天的三处病,都在真机量过(09-14 本会话):
- 发送后自己那条落底,回复在它下面一行一行往上顶,等待期间那段是三个点,首字到了点换正文,视口跟着每一段长高往上滚。
- 收尾那一帧思考段自动折叠:6 万像素一帧缩到 783px,上一条用户消息的 top 从 −60,879 跳到 −286(`probe-stream-end.mjs`),整屏跳变。
- 重试没有任何动画:按下去屏幕不动,等账本删完旧回复再从头画。

## 1. 一句话

**座位**:发送那一帧自己的话原位变气泡,滚到置顶线,最后一轮的下面留出「视口减掉置顶线以上」那么高的空白。之后等待、上下文更新、思考、正文、工具卡全在座位里长;**座位没长满之前视口一像素不动**,长满了自然接上今天的跟底。收尾只做两件事:思考段**锚住视口里正在读的那一行**折回一行;外缘那一行三张脸同格同高只换透明度。重试:按下即开槽,旧回答向上折进座位上缘(锚住自己那条气泡),同一帧折痕开始扫。

## 3. 座位模型(几何)

```
视口上缘 ─────────────────────────────  y = 0
        ── 置顶线 ──────────────────  y = --send-line (24)
        [自己那条气泡]
        [回复:折痕 / 思考 / 正文 / 工具卡 / 外缘那一行]   ← 长
        [座位垫块  data-seat]                              ← 缩(长多少缩多少)
视口下缘 ─────────────────────────────  y = clientHeight
```

- 座位高 `seat = max(0, clientHeight − sendLine − turnHeight)`,`turnHeight` = 从自己那条气泡上缘到回复下缘。**只在最后一轮上有座位**;发送新一条时上一轮的座位在同一次提交里由新气泡原位接管(上面的旧内容一像素不动)。
- 座位 > 0 时**跟底不发**(`grew` 不 stick):内容长进座位,视口不动。座位 = 0 之后照旧 pinned 跟底。
- 视口太矮(`clientHeight − sendLine < 3 行`)退化为今天的落底 + 跟随。
- 自己那条比视口还高:上缘落置顶线,座位取下限三行。
- 人往上翻(browsing):座位照旧,视口不追。
- 窗子 resize:座位重算,`scrollTop` 不动。
- 换会话 / 冷载:没有座位(座位是「刚发送」的产物,不落盘);切回停靠的会话时如果那一轮还在流,座位按当前几何重算。

## 7. 与既有法的关系

- `follow.ts` **一个字不改**:座位与折叠锚定都是 `ChatStream` 那只 hook 里几何层面的事(什么时候 stick、stick 前减多少),状态机判据「只有位置与意图」不变。
- 第四处 `scrollTop` 写点(滑到置顶线)与既有三处(进场 / 长高 / 扩窗补位)并列,判词写在它上面;JS 插值,不用 `scrollTo({behavior:'smooth'})`(定位不是动效,档「无」下照样工作)。
- 观察器回调只读不写(`project_resize_observer_loop_2026_09`):座位高经 `FrameCoalescer` 下一帧写;折叠补偿写的是 `scrollTop`(不改布局),允许在 RO 里直接写。
- 动效:`@keyframes` 只在 `styles/motion.css`(光扫沿用 `--kf-seam-sweep`);JS 时长只在 `components/motion.ts`(新加 `SEND_LAND_MS`=180 / `SEND_LAND_MAX_MS`=320 / `FOLD_MS`=180,与 tokens 镜像);`--send-line` 进 `tokens.css`。
- 三点(`ui/Dots`)在聊天区退役,丸上的三个点不动。

## 8. 留账

- 流式期间读数行跟着正文下缘走;重试档「上折 + 首字」撞在 400ms 内会出现一次先上后下。把读数行钉在座位底边是另一个拍点,本单不做。
- 「上一次回答」版本芯片:core 的 retry 是删掉重开,账本没有版本,先要账本支持。
- 座位不落盘:切走再切回时,如果那一轮还在流,座位按当前几何重算;已经收尾的不再有座位(与「换会话 = 一次新的进场,落底」一致)。
