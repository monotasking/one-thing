问题上一版为什么会这样（实测）这一版怎么做
要点两次才进编辑正在编辑一项时去点另一项：按下鼠标那一刻，编辑框失焦、整张列表重画；松开鼠标时按下时的那个元素已经不在了，浏览器就不发 click，于是这一下什么都没发生。进编辑改在按下鼠标那一刻完成：同一个处理里先保存上一项、再打开这一项，只重画一次，不等 click，也不靠失焦事件。
点了没反应的地方列表行之间有 4px 的缝、勾选框左边一截、行尾空白，点上去落在列表容器上，不属于任何一行。按下时找离鼠标最近的那一行，光标放在离点击位置最近的字上。悬停底色也铺满缝隙，看到的可点范围就是实际的可点范围。
悬停和编辑的样子悬停是一圈往外扩的灰影，包不住勾选框；编辑时是带描边的输入框，而且粗体、行内码在编辑框里变回普通字，字会跳。悬停只给列表行一层很淡的整行底（包住勾选框），段落和标题不画底。编辑中不加框，底色和悬停一样；粗体、行内码、链接照样显示，只多出淡灰的记号。
