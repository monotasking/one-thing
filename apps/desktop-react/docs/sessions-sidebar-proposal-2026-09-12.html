Sessions 侧栏 · 三个方向

2026-09-12 第二稿。先造一批随机长度的标题当真数据(下面那张表,8 到 70 个字,中英混着,每次点「换一批」都不一样),再按三个真正不同的方向各出一台。对齐规则:所有盒子的左缘 = 左侧红灯的中心(x = 16 + 6 = 22,虚线),没有任何东西越过它;文字在盒内再进 8。每台 240 与 320 两档并排放着;每扇窗右下角报这一屏摆下了几条会话、标题平均露出几个字。悬停、⋯、右键、搜索、范围、关闭 / 置顶 / 重命名 / 删除都是活的。

方向 A导航行 —— 顶部不是工具栏,是三行导航

新会话 / 搜索 / 项目各是一行,和会话行同一种形、同一个左缘,没有输入框常驻。点「搜索」那一行,它自己变成输入框(Esc 还原);点「项目」那一行弹范围表,行上写着当前范围。列表单行、32px、无时间列,标题从 x=16 起笔一直画到右缘;悬停时 ⋯ 从右侧盖上来,标题尾巴用渐变收掉。这是 ChatGPT / Claude 那一路:密度最高,一屏摆得最多。

取舍:看不到时间(节头「今天 / 昨天」替它说);项目名不在行上(范围行说了当前项目;「全部」范围里项目只在 ⋯ 菜单和 Quick Look 里能看到)。

方向 B双行便签 —— 标题给两行,行与行用细线分

一条会话是一张便签:标题最多两行(超出才截),底下一行 11px 的灰字放时间 · 项目。顶部只有一行:左边是范围名当标题(「全部 ▾」点它换范围),右边两颗图标 ⌕ 和 ＋;点 ⌕ 那一行原地变成搜索框。当前会话在左缘画一根 3px 的暖色条。这是 Apple Notes / Mail 那一路:标题几乎都能读全,代价是一屏少摆一半。

取舍:行高 52 起,240 宽一屏约 9 条(方向 A 约 14 条);细线分隔比圆角薄膜更「列表」,和壳里别的面(文件树)不是一种皮,但和便签这个形是一致的。

方向 C项目树 —— 按项目分组,范围选择器整个消失

列表就是一棵树:置顶在最上,然后每个项目一组、最后「其他」(没挂项目的);组头可折叠,组头就是范围,所以没有下拉、没有小牌。行 28px,单行,右端一格很淡的相对时间(「3 分钟前」「昨天」「9月3日」),悬停 ⋯。顶部一行:「会话」+ ⌕ + ＋。这是 VS Code / Finder 那一路:按项目找东西最快,日期退成每行的小字。

取舍:真店里 57% 的会话没挂项目,「其他」那一组会很长(样例按同一比例造的);想按日期扫最近在做什么,得看每行的小字而不是节头。房间的子行照旧缩进一级。
