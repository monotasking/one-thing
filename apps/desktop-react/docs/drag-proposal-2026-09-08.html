拖拽方案:一种东西在动、一种标记在指、三种落点

2026-09-08。对着你 09-08 报的六处难用,先把每一处的根因对到代码,再把整套拖拽收成三句话。下面的样例是能拖的,顶部那个开关可以在「今天的做法」与「方案」之间切,同一个动作两边各做一遍,差别就在手上。

一、你报的六处,各自是什么病

拖拽莫名变成了钉到边上(pin)已定位 窗口四条边各有 24px 的「边带」,拖任何东西经过那里松手就会钉成一条架子,而且它优先于内容区落点。从浮窗里拖一行会话出来,手一靠边就进了这条带。 边带收窄、退后、说清楚:只有 12px 宽(原来 24),只在那一边还没有架子时出现(有架子就直接落进架子的条或内容区),排在标签条之后、内容区之前,带一层薄膜和一句「钉成右侧架子」。想不小心钉上得把手压到窗口最边上 12px 里。拖浮窗标题栏到边上、右键「钉到 ▸」两条路照旧。
浮窗顶到上栏,被窗口拖拽区挡住拖不动已定位 浮窗矩形的钳位允许 y 到 0(clampFloatRect),而顶栏是 Electron 的原生窗口拖拽区,它在原生层拦截、不看 z-index,也不接受别的分支上的 no-drag(07-21 实测过的规则)。浮窗标题栏一旦压进那 44px,就永远点不到。 浮窗的活动范围从顶栏底缘起算:钳位、撕出落位、边上弹回三处都读同一个上界。浮窗永远不可能进那条带。
关掉之后 sessions 上还显示没关待复现 Dock 瓦上的「开着」小点读的是形态机自己的摆放表(placements),而会话内容是拼贴树里的一格,两本账各记各的。你那一串操作(拖出、钉边、关掉)走完之后,两本账很可能已经对不上。这一条我还没在真机上复现出完整链路,先按两本账不同源立案。 「开着没有」只有一个来源:拼贴树里有没有一片叶装着它。Dock 的小点、会话列表的小点都从树上算,不另记。
从 sessions 拖到标签正中会闪已复现 外来来源落到同一条条上有两种落点在交替:正中 44% 是「二合一」(描圈),两侧各 28% 是「插到第 n 位」(空位)。每过一次 28% 那条线,空位就被删掉再重新插一个新的(从 0 宽起动画),右边所有标签整排跳一格宽;而判据读的是起拖时的基准几何,空位一开活布局就和基准差一格宽,圈还常常落到指针右边那一格。 外来来源落到标签上一律是「插到旁边」,删掉「标签正中二合一」这一档;空位只挪不删;条上的下标按活几何判(活几何加「空位插在第 n 格之前」是自稳的,左边的标签永远不动,右边的中线永远在指针右侧)。

上一轮真机还确认了三条与这些同源的:二合一那一形目标标签的描圈被抬起的标签盖住 92%;换序途中按 Esc 是瞬移不是滑回;右键按在非活动标签上会先切标签。三条都并进下面的方案。

二、方案:三句话

1. 一种东西在动

条内换序时动的是标签本身;离开条之后动的是一张卡片,卡片下面挂一行「松手会怎样」。屏幕上任何时候只有这一样东西在跟手,其它一律不变色。

2. 一种标记在指

落点只用一个标记指出来,而且是同一个节点在挪:在条上是一格空位,在内容区是一块半透明板(整块 = 开成新标签,左右半块 = 与它并排),在空白处是一圈虚线窗轮廓。没有薄膜、没有描圈、没有氛围。

3. 三种落点,外加一条窄边

插到条上、与内容并排、撕成浮窗。还没有架子的那一边,窗口最边上 12px 是「钉成新架子」,排在最后、有薄膜有字;「压到标签上二合一」那条带删掉,二合一只有一种手势:拖到内容区左右两侧。

4. 按下即激活,但只认主键

左键按下当场切标签,松手不动就是一次点击;右键只开菜单不切标签;中键什么都不做。Esc 与失焦都是 150ms 滑回,不瞬移。

5. 关得掉、算得清

只有中央区必须留一格会话;别处的会话标签都可关。「开着没有」只从拼贴树上算。浮窗永远在顶栏之下。

删掉的

氛围层、24px 抢先于内容区的边带、标签下压二合一(onto 带)、标签正中二合一(pairTab)、描圈这种画法、右键与中键的激活。删的比加的多。

三、架子:四边都能有,每一条都是一片叶

架子(钉在窗口四边的面板)在这套方案里只有一句定义:架子就是一片叶,一条标签条加一块内容,和顶栏那条标签条讲同一套话。左、右、上、下四边都能有,规则一样,于是它的一切行为都从上面三句话推出来,不另立规矩:

  • 架子怎么生出来:三条路。拖一扇浮窗的标题栏到窗口任一边 24px 内松手,浮窗塌成那一边的架子;在标签 / 浮窗的右键菜单里选「钉到 ▸ 左 / 右 / 上 / 下」;或者把一格标签、一行会话拖到还没有架子的那一边窗口最边上 12px 里,薄膜亮起、写着「钉成右侧架子」,松手就有了。第三条是从前那条 24px 边带的收窄版:窄一半、只在没架子时出现、排在标签条之后,所以你 09-08 那句「莫名进了 pin 模式」在结构上不会再发生 —— 从前是手一靠边就钉,现在得把手压到最边上那 12px 里、还得先看见薄膜。
  • 内容怎么进架子:架子已经在了,它的标签条就是一条普通标签条,内容区就是一块普通内容区。拖到它的标签条上是插到第 n 位,拖到它内容区中间是开成新标签,拖到左右两侧是与它并排。标记也是同一个:空位、半透明板。面板(比如会话列表、目录树)也是架子里的一格标签,可以和文件、会话并排住在同一条架子上。
  • 内容怎么出架子:架子上的标签按下即激活,横拖换序,竖拖撕下;撕下之后的三种落点与顶栏的标签完全相同,包括拖到另一条架子上。最后一格被拖走或关掉,架子自己消失。
  • 架子自己的三件事不变:收起成一根细梁、点梁展开、拖分隔杆改厚度。这三件今天就有,方案不动,只补一条:它们和分隔杆、浮窗一样要接 Esc 与窗口失焦,拖到一半切走应用不该留下一根卡住的杆。
  • 会话进架子关得掉:「至少留一格会话」只对中央区数,架子里的会话标签照常可关。

面板也是标签左侧架子里的「Sessions」就是一格标签:把一个文件标签拖到它旁边,两者并排住在左架子上;把「Sessions」拖到顶栏,它就成了中央区的一格。

浮窗顶到上栏把那扇浮窗往上拖。「今天」它会钻进顶栏,然后标题栏点不到;方案在顶栏底缘停住。
