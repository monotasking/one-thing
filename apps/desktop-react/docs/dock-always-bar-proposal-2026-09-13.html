Dock 常驻 · 让出来的那条带就是 Dock 自己

已被推翻,留档。这一页是 2026-09-13 早些拍板的「整边浮栏」(实现见 0aa2a0026),同日晚被用户两句话推翻:「dock 的长度不要默认占满,他应该该多长就多长」「我要的效果是,他不影响其他 element 元素的 background,不需要自己设置,他就是一个独立的悬浮的块」。今天的形是:两档都是药丸,常驻档只多一条让位带,带子不设任何底色。留住的三件是平移形让位、--dock-thick 式子、容器不进顶栏带 —— 现行判词在 apps/desktop-react/CLAUDE.md。下面的图与文字保留原样,只作为那一版的记录。

让位保留 —— 主区仍朝 Dock 那条边退一段,别的东西一件不被盖。变的只是常驻形态下 Dock 长什么样:不再是一枚浮在空带中央的药丸,而是一条贴满整条边的浮栏,皮与 Composer 同一身(玻璃、描边、圆角、四周 12px 留白),瓦在栏里居中(或按沿边对齐档靠前 / 靠后)。带子的颜色于是永远是栏自己的玻璃,底下换哪一页都一样;栏外那圈 12px 留白与 Composer 四周的留白是同一块地。四条边同一个形:横边是一条横栏,竖边是一条竖栏。

怎么看:切「终端」—— 左边终端的黑底停在半空,底下露一条纸色,药丸压在纸色中央,那条纸色就是你说的「颜色不一样」;右边终端照样在让位线上结束,但让出来的那截整个是 Dock 的玻璃栏,没有第二种颜色。切「左 / 右」—— 同一条栏竖起来,主区整体朝里退,Sessions 面板照旧是整块。沿边三档只挪栏里的瓦,栏自己永远满边。放大仍在(悬停瓦),向栏内侧长。
