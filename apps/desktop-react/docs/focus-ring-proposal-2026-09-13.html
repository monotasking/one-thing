焦点环比稿

三种样式共用同一份载体契约,上面这一排切的只是四个 token。按 Tab 走一遍,或者点「全部点亮」一眼看完。

甲 · 柔光环(今天的形,收口后的版本)

3px、强调色 18% 透明,贴着盒边。文本输入落焦时边线一起升到强调色。

气质最软,和暖纸面最合;代价是浅色面上对比最低,深色面上要靠边线升色才看得清。

乙 · 硬线环(Chrome / GitHub 那一路)

2px 实线强调色,离盒边 2px,中间露出一圈底色。边线不动,环独自说话。

任何底色上都读得出(这是无障碍规范对焦点外观的那条要求);代价是最占地方,贴边的控件会被容器裁掉。

丙 · 内嵌描边(macOS 列表 / Figma 那一路)

2px 实线画在盒里,不越界一像素。文本输入落焦时边线升色,与内环叠成一道加粗的强调边。

永远不会被滚动容器裁掉、不会压到邻居(标签条、Dock 瓦、密排的行);代价是小控件里环会吃掉内容边距。

基础控件

按钮 · 图标钮(只在键盘落焦时亮)
分段器 · 标签(带自己投影的元素,环不能被投影顶掉)
文本输入(鼠标点进去也亮)
勾选 · 单选(环在盒上,不在那个看不见的原生控件上)

复合载体

Composer 面板:环画在整块面板上,只认里面那个文本框的焦点;发送键落焦时是它自己的环,不叠面板
列表行 · Dock 瓦(密排元素,看环会不会压到邻居)

会被裁掉的那种位置

滚动容器里贴边的行:甲、乙的环外扩,会被 overflow: auto 切掉一半;丙画在里面,完整
壳里要改的地方

配方:tokens.css 四格。
规则:global.css 一组选择器(上面那七行)。
消费方:28 个文件删掉自己那句 outline / box-shadow,元素上加一个 data-focus-ring。
