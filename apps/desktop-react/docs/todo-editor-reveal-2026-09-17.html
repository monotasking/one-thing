元素档（默认，和 Typora 默认一致）：只展开光标所在或贴着光标的那一个行内元素；整块档（Typora 的「聚焦时显示简单块的源码」）：点进哪一项，整项记号都露出来；不显示记号档：编辑时也永远看不到 markdown 记号（像 Notion），光标所在的元素铺一层淡紫底，⌘B ⌘I ⌘E 加 / 去粗体、斜体、行内码。
为了回答「光标会不会对不上、看不到」：编辑框下面有一行光标读数，实时显示光标在原文里的位置（红色 ‸）、展开了哪些元素，以及一项自检——屏幕上的光标和原文位置对不对得上、光标两边的字是不是都看得见。右边是测试用例，点「放到这里」把光标放到指定位置，然后按提示用键盘走一遍。

光标规则（三档共用，唯一的区别是记号显不显示）
  1. 同一个画面、同一个动作，结果相同：光标落在哪只取决于屏幕上现在是什么、光标在哪，不取决于你之前按过什么。
  2. 整篇是一个文档：← → ↑ ↓、⌥←→（按词）、⌘←→ / Home End（行首行尾）、⌘↑↓（全文首尾）都不在项与项之间断开；第一项再按 ↑、最后一项再按 ↓，光标不动。
  3. 目标列：第一次按 ↑↓ 记下光标的横坐标，之后只要光标没被别的动作挪过就一直用它（同一项的折行和跨项同一种量法）；点鼠标、←→、打字、Home/End 都会重新定列。
  4. 一步 = 一个看得见的字（emoji 算一个）；两个看得见的字之间藏着记号时：往右走停在记号左侧、往左走停在记号右侧、鼠标一律取靠左；不显示记号档只有一个位置：跟左边那个字走。
  5. 键盘动作永远不让光标消失（只有 Esc 和点到外面会）：回车拆项 / 标题回车新起一项 / 空项回车退一层或删掉；行首退格依次是 删空项 → 标题引用降成段落 → 退一层缩进 → 并到上一项；行尾 Delete 把下一项并进来。
  6. 一条撤销历史：打字、拆项、并项、缩进、勾选、加格式都在里面；撤销把光标放回那次改动发生的地方，不管你之后去了哪一项。
  7. ⇧ 扩选只在一项之内：扩到这一项头尾就停（跨项选区不做）。
