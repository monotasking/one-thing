    七条规矩

    ① 发送只滚一次,不切屏:自己的话滑到置顶线(缓出;短路 180ms = --dur-land,一屏的路拉到 320ms;档「无」一步到位),之后视口不动,直到座位长满。
    ② 座位 = 视口减掉置顶线以上,最少三行;窗子变矮只改座位不改滚动。
    ③ 等待画在折痕上,不占布局。上下文更新落账 = 折痕转成在流里的一行、标签淡入(等待期间转,座位有地方)。首字到:有上下文更新的折痕留下(光停、线实、标签常驻,正文从它下面起);空折痕淡出(120ms),正文从线的位置起 → 位移 0。
    ④ 思考流式中展开,收尾折回一行,折叠期间每帧把正文首行钉在原处(scrollTop 补差)。
    ⑤ 外缘那一行三张脸同格同高:读数 → 动作 / 收场通知,只换 opacity。
    ⑥ 重试按下即开槽:旧回答向上折进座位上缘(180ms),同一帧折痕开始扫;没有第二种「进行中」。
    ⑦ 人往上翻就是浏览:座位不收、视口不追,丸说「已发送 / ··· / 回到最新」(既有三张脸)。
