Composer · 三台完全不同的样例

每台都能真打:输入 @ 拉文件、/ 拉命令与技能,↑↓ 走位,⏎ 选中,再 ⏎ 发送,发出去的那条气泡里引用都能点。右上角切三档宽度,框右下角也能拖(样例用容器查询,不看窗口宽度)。三台差的是交互模型,不是皮:A 把选择器锚在光标上、B 把命令当命令行、C 把引用从正文里拿出来放托盘。

① 气泡不渲染ChatStream.tsx:1083 用户消息是 {message.content} 纯文本;@/绝对路径 原样露出,没有链接、没有 markdown。

④ 命令无提示行上只有 name + desc,选中后 usage(/cd <path>)从不上屏;匹配只按 name 前缀,不看描述;用法错只在发送后 toast。
