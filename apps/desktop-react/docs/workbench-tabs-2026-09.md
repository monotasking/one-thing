# 拼贴台 v3 方案：标签条与拖拽

接续 `workbench-2026-09.md`。09-05 用户真机三轮报障与四条裁定。

## 核心推翻与改造

**中央区重设**：v2 中央区两条推翻——
- ✗ 任意分屏树不再暴露给用户（弃多棵并排树）
- ✗ 顶栏不再按叶分组画多条标签条（一条标签条 = 一片叶）
- ✓ 中央区 = 一片叶 + `pair` 内容种类

**pair 内容种类**：
- 承载两个并排格（key = 两个 refId）
- 两格各自 `renderRef`，拆开/二合一是 `replaceRef` / `insertTab` / `removeTab` 的组合
- core 零新概念（session ContentKind 层无变动）

## 标签条与手势设计

### 参考手感一张表

| 界面 | 行为 | 启示 |
| --- | --- | --- |
| Chrome | 按下即选中标签（不拉动） | 激活路线 |
| Chrome | 横向拖动换序 | 换序是标准路线 |
| Chrome | 竖向向下撕下 | 撕下成浮窗 |
| Arc | 拖到另一标签上 → 并排 | 并排的手势入口 |
| macOS 弹簧文件夹 | 停驻自动展开目录 | 停驻阈值 |
| VS Code | 落半边区域预览 | 落点圈的视觉反馈 |
| macOS / Figma | 拖拽时 app 图标摇晃 | 每一步拖拽都有回应 |

### 手势状态机与阈值表

| 常数 | 值 | 理由 |
| --- | --- | --- |
| `DRAG_START_X` | 6px | 水平容差（Chrome 6，Safari 4） |
| `DRAG_START` | 8px | 拖拽启动距离（iOS 推荐值） |
| `TEAR_OFF` | 24px | 竖向撕下阈值（高于标签条 h=32） |
| `DWELL_MS` | 300ms | 停驻激活目录（弹簧文件夹 400，降低响应） |
| `DWELL_PX` | 4px | 停驻期间容差移动 |
| `NEIGHBOR_MS` | 120ms | 跳邻标签快速间隔 |
| `SETTLE_MS` | 150ms | 拖拽结束动画时长 |
| `PAIR_BAND` | 28% | 二合一视觉提示宽度（标签宽度） |
| `TAB_MIDDLE` | 44% | 标签正中判定点（非 50%，留换序尾部） |

### 落点与反馈九行表

| 落点区域 | 拒绝 | 标签正中 | 标签之间 | 窗口边带 | 内容区右带 | 内容区左带 | 内容区中间 | 自己的内容区 | 窗外 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **操作** | ❌ | ✓ 选中 | ✓ 插入 | ✓ 靠停 | ✓ 撕下浮窗 | ✓ 撕下浮窗 | ✓ 撕下浮窗 | ✗ 拒绝自己 | ✗ 系统处理 |
| **反馈** | 禁止标识 | 高亮 + 闪烁 | 分隔杆亮 | 停靠圈亮 | 浮窗轮廓 | 浮窗轮廓 | 浮窗轮廓 | 灰显 + 抖动 | 无 |

**两条贯穿规则**：
1. 起拖即淡亮所有能放处（所有非拒绝落点）
2. 浮影下一行字永不空（拖到任何位置，浮影内容区始终有标签名）

**反馈同一节点挪不重建**：拖拽在同一个目标区域内微调位置时，不重新渲染整体布局，只更新光标/指示线位置。

## 文件面板多开与出厂摆法

### 文件面板按目录多开

- **扶正 `files-root:<dir>` 形态**：`refId = 'files-root:~/.onething/projects'` 等
- **瓦改为「目录」命名**（不再称「文件浏览器」）
- **最近目录表**：侧栏记录最近打开的 5 个目录，快速切换
- **同名带父目录**：标签名冲突时自动显示 `file.txt (Desktop)` / `file.txt (Downloads)`

### 预览标签整体退役

- ✗ 预览模态（含真机复现出的 `tree.insertTab` 对已开 ref 提前返回致 `↵` 固定失效的 bug）
- ✓ 出厂档改主区域新标签（打开文件默认占据一个主标签位）
- ✓ 出厂摆法改左架子（旁通预览标签，真机复现：「拖不到聊天区」是文件面板浮窗盖在聊天区中间）

## 键盘与菜单等价 + 播报

- 所有鼠标拖拽操作有等价的菜单项或快捷键
- 拖拽过程中屏幕阅读器播报当前落点类型
- 结束时播报最终操作（选中 / 插入 / 并排 / 撕下）

## 二合一细节

| 方面 | 规则 |
| --- | --- |
| 焦点 | 拆开后焦点留在右格；合并后焦点在合并目标 |
| 标题 | 并排时两个标签名都显示；二合一标题用 `+` 分隔 |
| 格头 | 各格独立操作栏（关闭、选项等） |
| 拆开 | `split` 操作变 `replaceRef`（一格保留，另一格变新标签） |
| 关闭 | 单格关闭只关那一格；若仅剩该格则关闭整个标签 |
| 分隔杆 | 可拖动调整宽度比；双击还原 50:50 |
| 持久化 | `refId1:refId2` 对序列化到设置；启动时恢复 |
| 约束 | 不允许三格与嵌套（一对最多两格） |

| 周期 | 任务 | 交付 |

### 验收八条可自证

1. **拖拽启动**：按住标签 50ms 不动，鼠标图标变抓手
2. **换序**：同标签条内拖拽标签左右互换，无闪烁
3. **撕下**：竖向拖 30px 外，浮窗出现，松开时浮窗停靠
4. **并排**：拖标签到另一标签上 300ms，自动二合一，无闪烁
5. **拆开**：二合一标签双击分隔杆，恢复两标签
6. **落点反馈**：每次指针移动，视觉反馈 16ms 内更新（无卡顿）
7. **键盘等价**：菜单项执行与拖拽结果一致
8. **性能**：拖拽帧率 ≥ 55fps（最长单帧 ≤ 18ms）

```bash
bun run gate:drag

```
