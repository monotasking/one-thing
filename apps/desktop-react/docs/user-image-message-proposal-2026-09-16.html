带图的用户消息 · 三种形

同一组对话在三台里各画一遍:① 一张截图 + 一句话,② 四张图 + 一段较长的话,③ 只发了一张竖长的手机截图,④ 一张还在加载、一张读不出来。今天的样子是「字在上、每张图 14rem 宽排在下面、每张图下面再挂一枚文件名 chip」—— 三张图时气泡被拉得很长,文件名重复了一遍图本身已经说的事。三台都去掉了逐张的文件名 chip(文件名在悬停提示和大图预览里)。点任意一张图看预览,点右上角「选这个」。
