模型覆盖 · 上下文窗口与工具调用

每一行动作列里一颗滑杆钮,点开一张锚在钮下的浮层,只装两格:上下文窗口、工具调用。手填的与目录里有的都能开 —— 覆盖是给「目录没填」和「目录说错了」两种情况的,不只给手填。下面三张表可以真点:钮开合、分段切换、数字框输入。
