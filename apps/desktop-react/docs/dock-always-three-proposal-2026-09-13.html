Dock 常显 · 三案(掷骰子起的)

先跑脚本得三串数字、三串字符串(seeds.mjs,系统随机源),数字前四位各翻一根设计轴:落点 / 形 / 密度 / 运行态怎么画。三次「形」都掷到了胶囊分组,那就当三案的共同点。三扇窗内容同步,切上面的 tab 与工作区,看每案怎么应对。三案都独占自己那条边,内容区从一开始就不被盖 —— 上一张页论证过的前提这里不再重复。

主区 tab 工作区

案 1 · 胶囊群

79094236 · UhXoj8oQ9v

一条药丸拆成三粒胶囊:工作区 | 会话组 | 工具组 | 加号,各是一粒,粒间露地。药丸「浮在一片空地中央」的怪感来自它是一整块;拆开之后它是几件小家具摆在自己的地上,像 iPad 的坞。运行态不再画点,图标描边加粗一档、换强调色,再垫一层淡底,远看就分得出「开着的」。放大保留,但只在胶囊内。字符串里连着的 o、Q、9 就是这几粒圆。

案 2 · 工作条

09959116 · 5tvPlbBaFL

Dock 变成一条整边的工作条(VS Code 状态栏 + Windows 任务栏的合体):左边一粒胶囊是启动器,中段随当前 tab 变 —— 聊天显示模型与用量,终端显示 cwd 与 shell,改动显示分支与加减行,浏览器显示域名与安全态;右边是通知、agent 状态、时钟。它常显不奇怪,因为它每时每刻都在告诉你一件事,不只是一排入口。徽记直接落在瓦角上。放大关。

案 3 · 顶栏坞

29663798 · mgiCIWMaMi

坞搬进顶栏,与红绿灯同一行(Arc / Safari 的工具栏位置):底边整个还给内容,没有让位这回事。瓦缩到 26,只画当前工作区用得上的那几块,其余折进「+N」;切工作区那一粒色块就在右端,坞跟着换一组。运行态是瓦底一道 2px 边缘高亮,与 tab 条的选中线同一种语汇。顶栏本来就是常显家具,坞住进去就不再是「第二条常显的东西」。
