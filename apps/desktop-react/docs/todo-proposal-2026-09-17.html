待办接进 React 壳 · 三个候选

后端早就有了：待办就是 ~/.onething/todo-plan/ 下的 markdown 文件，分两种——你自己的清单（user-notes/*.md，全局），和 AI 在每个会话里给自己写的计划（sessions/<会话>/ai-todo.md，AI 用普通的写文件工具维护）。缺的只是 React 壳里没有任何一处能看见它们。下面三台都能点：勾选、改字、回车加一项、清空后退格删掉、左栏切会话、点「模拟 AI 推进一步」看 AI 改文件时界面怎么反应。

A · 一个 Dock 面板装两种右边一块「待办」面板，顶上切「本会话 / 我的清单」。一处入口，好找；代价是看 AI 计划要先开面板、再切到那一页，平时聊天时看不见。
B · 计划跟着对话，清单进 Dock推荐AI 计划收成输入框上方一行：进度 + 下一步，点开是抽屉；会话没有计划就不出现。你自己的清单是全局的，放右边 Dock 面板。两种东西性质不同，各放在它被用到的地方。
C · 独立待办应用作为一格内容打开，占整个台面：左栏列出本会话计划、你的清单、其他会话的计划，右边大字编辑。适合集中整理、回看所有会话的计划；代价是和对话不在同一屏。
三台共用的规矩（不管选哪台都这么做）
  1. 文件是真相，界面只是它的一种读法。勾一项只改那一行的 [ ]→[x]；标题、说明文字、代码块原样保留并照样显示。右上「源文件」可以随时看到原文。
  2. AI 改了文件，界面当场跟上。被改的那一行淡淡闪一下，头部出现「AI 刚更新」，一秒多后自己褪掉——你知道它动了哪里，但不会被打断。
  3. AI 计划跟随当前会话。切会话就换成那个会话的计划；没有计划的会话不显示空壳（B）或给一句说明（A / C）。
  4. 一项的其余动作（删除、挪位置、复制）只放右键菜单，行上不挂悬停按钮——照壳里「动作单产地=右键菜单」那条规矩；样例里没画菜单。
  5. AI 计划按原顺序显示（步骤有先后）；你自己的清单可以「隐藏已完成」。
候选

状态表（以 B 为例，A / C 同一套状态换位置）

状态计划条（输入框上方）清单面板（Dock）
会话没有计划不出现，输入框上方什么都没有照常
有计划、进行中「计划 9/12 · 下一步 …」，点开抽屉可勾可改照常
AI 刚改了计划「刚完成 …」橙字 1.4 秒后退回「下一步」；抽屉开着时那一行闪一下—
计划全部完成「计划完成 12/12」灰字，不再提「下一步」—
文件读不到 / 被外部删了计划条消失（同「没有计划」）该清单从列表里去掉，选中项落到第一张
还没有任何清单—一句「还没有清单」+「新建清单」
正在编辑一项时 AI 也改了同一个文件以文件为准重读；你正在打字的那一行不被覆盖，失焦时再按行写回（实现时要做行级合并，样例不演示）
