# onething

**mood** — 一张同时只摊开一样东西的工作台。手上这件事被完整照亮：标题是大的，正文是可读的，输入框是一块实实在在的白；
其余的东西没被收走，只是各自往后站了一步——面暗一档、字淡一档，需要时一眼能找回来。不喊、不闪、不用颜色抢人，
走开十分钟回来，你还知道自己停在哪一件事上。

## Direction
**层级只由面色承担。** 面取自 Flexoki ramp 的连续档位，相邻层跨足够大的一步（亮 ≈7 L、暗 ≈5–10 L）；
撤掉全部阴影与描边后画面不变——`box-shadow` 全置 none 重渲已验证。第二条是**焦点 / 退后**：
`.is-focus` 与 `.is-receded` 改写同一组语义变量，退后区域在面与墨上各退一档，"一次只做一件事"因此是一条能被 CSS 检查的规则。

## Color
一枚色 ≤ 两种含义。**橙**（`#BC5215` / `#DA702C`）= 人的操作：发送、新会话、选中条、你的消息底。
**青**（`#24837B` / `#3AA99F`）= 助手与系统在陈述：助手标记、工具卡脊线。状态色只出现在状态语义上，
一律软填充胶囊；全屏只有一处实心强调块：**发送**。

## Type
Public Sans + Noto Sans SC，全站无衬线，层级靠字号与字重。8 档字阶：12 / 13.5 / 14.5 / 正文 15.5 / 18 / 21 / 26 / h1 32
（= 2.06× 正文，行高 1.65）。mono 只出现在工具卡内部的路径与差异数字上。

## Do / Don't
**Do** — 容器先靠面色成立，1px 线只做同一块面内的分隔；控件永远比它所在的卡再高一档；一屏一个焦点，其余同时退面与退墨。
**Don't** — 别用阴影或发光环补层级（撤掉阴影画面必须不变）；别让相邻两层只差一个 ramp 档；别在同层里既凹又凸（输入框永不做凹槽）；别把一枚颜色同时当主行动、选中、链接和状态。
