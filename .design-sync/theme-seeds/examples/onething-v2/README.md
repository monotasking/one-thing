# onething · v2（2026-08-16）

**Mood** — 一张放着三块板的桌子：手边的会话、正在做的一件事、这件事的资料。工具在干活，界面不表演。

**Direction** — 桌面工具密度，不是营销稿密度：UI 13px、行高 28px、轨内留白 8px、控件 26–32px，15px 只留给阅读栏（680px）。三块面板浮在有色的地上，通道 8px、圆角 10px（S1/S4）；**面板里几乎什么都不装盒**——消息、文件行、用量行都直接躺在面上，靠墨阶与 4/8 节奏分组（组内 4–8、组间 16–26）。选盒装 vs 齐平：选了盒装，因为窗口三个区域的职责完全不同（选择 / 工作 / 参数），通道比线更快地说明"这是三件事"；但盒子只画到面板这一层为止。

**Signature** — **工作痕迹卡（work receipt）**：全屏唯一被装盒、唯一用 mono、唯一有强边框的东西。人话标题（写入了 3 个文件）+ 右端等宽耗时 + 每个文件一行（路径前缀退一档、加减用墨阶比例条而非红绿）+ 逐行状态（待运行）+ 状态丸与动作。它还有折叠态（读了 2 个文件 · 0.4s），证明它是个有状态的组件而不是一张插图。Agent 干的活因此是屏幕上分量最重的内容，这正是 onething 的主张。

**Color** — 地 `#E9EBEE` / 面板 `#FFF` / 卡 `#F4F5F7` / 嵌套 `#ECEEF1`（dark：`#0F1012` / `#1A1B1E` / `#232529` / `#2C2E33`）。墨四档承担层级；线 ≤ 11% 且只做辅助。强调蓝 `#3B6FD9`（dark `#7AA2F7`）**只出现三处**：选中会话的 2px 左脊、助手标记、焦点环。唯一的填色按钮是墨色的「发送」。状态色只做 20px 软底小丸。

**Type** — Geist（本地子集）+ Noto Sans SC，mono 只在工作痕迹卡内。字号五档：11 元信息 / 12–13 界面 / 15 阅读 / 21 会话标题；标题字重 500，无粗体。数字全部 tabular。

**Do** — 图标 16px、描边 1.75，行、按钮、页签都带；hover 用嵌套底不用线；数字右对齐成列。
**Don't** — 不给用户消息上底色、不做彩色按钮、不给内容加阴影、不把同一枚色派五种用途。
