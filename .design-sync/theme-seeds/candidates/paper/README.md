# paper

**mood** — 一份排得很好的文档。安静、有余白、可以读一下午。
不是终端，不是仪表盘，是你自己的 Notion 页面。

## Direction

层级靠**面**，不靠线。三个面各有各的材质：
**地**是暖纸（左右两栏再暖一档，自然后退）；**卡**是纯白 + 1px 描边、12px 圆角、**不投影**；
**浮层**是全屏唯一带阴影的东西——阴影在这里是"我浮在上面"的语义，不是装饰。

对话当文档排：你的话是一块暖色引用，AI 的回复直接落在纸上，正文 15.5px / 行高 1.68。
工具卡是 Notion 页面里的一张看板卡——有标题、有条目、有底部状态条，**不是终端输出**：
路径没有 mono，只有文件名是实墨、目录名退到 44%。

**签名件**：工具卡里的 diff 数字变成小彩色胶囊（+128 绿 / −41 红 / 待运行 灰）。
全站彩色只在胶囊里出现，其余是一种墨的三个透明度。
## Color

`#F5F3F0` 暖纸地 · `#EFEDE8` 两侧栏 · `#FFFFFF` 卡 · `#EDEBE6` 用户消息块
墨 `#1B1A17`，三档：100% 标题正文 / 62% 次要 / 44% 元信息
唯一饱和蓝 `#2B62DE`，**全屏只填充一次**——发送按钮。
胶囊：绿 `#1B7A46` / 红 `#B23A2B` / 琥珀 `#8E5A0C` / 蓝 `#2450BE`，都配 8% 底。
## Type

Public Sans + Noto Sans SC 一套走完，人文无衬线，字重扛层级。
h1 36px / 700 / 字距 −0.028em，是屏幕上唯一的大字，比正文大一倍多。
衬线（Source Serif 4 + Noto Serif SC）**只出现一处**：右栏那句说明。它是引文，不是标题。
## Do

- 主行动是白卡描边按钮，把唯一的填充蓝留给输入框——输入框才是最该被点的。
- 分组标题说人话、句首大小写、12.5px 中等灰，不加字距。
- 数字右对齐用 tabular-nums，但用正文字体。
- 留白分节，能不画线就不画线。
## Don't

- 不给卡片加阴影。阴影只归浮层。
- 不出现第二个填充蓝按钮。
- 不用 mono 排界面文字（路径也不用）。
- 不让彩色跑出胶囊——没有彩色边框、彩色标题、彩色图标。
