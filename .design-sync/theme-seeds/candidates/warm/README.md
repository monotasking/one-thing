# warm · 暖砂 Warm Sand

**Mood** — 像一张摊在木桌上的暖砂色纸。卡片轻轻浮起，字大而稳，工具在旁边安静地干活。
不是落地页的暖，是可以坐八小时的暖。

## Direction
- 地是砂（`#f4e9d7`），侧栏更沉一档（`#ebddc5`），卡是暖白（`#fffaf2`）——三层面，一眼分得清。
- 左对齐、不对称：正文栏封顶 720px，右边留白是设计的一部分，不用东西去填。
- 圆角 14→18→24，按钮全是胶囊；阴影只有两档，色相调到暖褐，所以卡"浮"而不"切"。
- 密度中等：行高 1.66，卡片内边距 20，工作八小时不会觉得挤。

## Color — 两个声音
| | |
|---|---|
| 陶土 `#c67139` | **你**：新会话、发送、你的消息、选中的会话、焦点环 |
| 鼠尾草 `#7a8a5e` | **助手**：AI 头像、工具卡的脊线、已完成、新增行数 |
| 琥珀 `#b3813a` | 进行中 / 待确认 |
| 砖红 `#a94b3a` | 失败 / 删除行数 |

强调色不是装饰，是"谁在说话"。所以工具卡左边那条鼠尾草竖线一出现，你就知道那是机器干的活。

## Type
- 标题 **Fraunces / Noto Serif SC 700**，34px——一屏一个大标题，只此一处用衬线。
- 正文 **Figtree / Noto Sans SC**，15.5px / 1.66；次级 14.5px；最小 12.5px 只给时间戳和快捷键。
- 路径和差异数字用 IBM Plex Mono，13.5px，等宽对齐——只在工具卡里，不外溢到界面标签。
- 字体已子集化内嵌（`fonts.css`），离线渲染也是对的字。

## Do
- 主行动只有一个，永远是胶囊、永远是陶土。
- 面板小标题说人话（用量 / 保留策略 / 状态），13.5px 半粗，不是 mono 大写。
- 输入框是屏幕上最亮、阴影最重的东西；聚焦时描一圈 3px 陶土雾。
- 数字右对齐、tabular-nums；单位缩到 13.5px 跟在后面。

## Don't
- 别再给正文加一层卡：AI 回复直接落在砂地上，浮起来的只有它干的活。
- 别用鼠尾草做按钮——它是助手的颜色，不是行动的颜色。
- 别把砂底提亮成米白，也别把陶土用满整块面积；暖色一大片就变广告页。
- 别用 1px 细线分区，分区靠面和间距。
