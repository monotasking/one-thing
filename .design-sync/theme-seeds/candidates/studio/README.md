# studio · 夜灯

**mood** — 深夜书房里开着一盏暖灯。地是近中性的暖黑，卡片是真的浮起来的一层，
一点橙色落在最想让你按的地方。暗，但不冷、不硬、不像终端。

## Direction

**对照实验**：留住产品默认的暗色，把"账页画线"整套语汇丢掉。参照 Linear /
Raycast / Arc——暗色也可以是友好的。它想回答：用户讨厌的是**暗**，还是**账页**？

分层不靠线，靠**面的明度**：#151413 地 → #1a1918 主地 → #232120 侧栏 →
#2a2827 卡片 → #302d2b 输入框。1px 线只是面的收边，从不独自承担分区。
输入框是全屏最亮的一层，脚下一圈暖光——它是你最想点的东西。

## Color

`#1a1918` 暖黑地 · `#232120` 面板 · `#2a2827` 卡片 · `#302d2b` 输入框
`#da702c` 唯一强调（Flexoki 橙） · `#efebe5` 主文字 · `#8d857a` 弱文字
状态点：`#8faa74` 完成 / `#d0a215` 进行中 / `#d97066` 失败。
橙色只出现在三处：主行动「新会话」、发送键、AI 的身份标记。

## Type

Inter + Noto Sans SC，全字重同一族。标题 32px / 650，正文 15.5px / 行高 1.68，
小节标题 13px 常规大小写常规字重（今天 / 用量 / 保留策略 / 状态）。
数字用正文字体；mono 只在工具卡里出现，因为那里写的确实是路径和行数。

## Do

- 需要一个新层次时，先想"这是不是更亮的一层面"，再考虑加线
- 界面标签说人话：「还没跑」「还需要你确认这次迁移」「超过 90 天的会话只删正文」
- 数字带单位、带对象：312 个 / 567 KB / 3 天前，不是右对齐的裸数字列
- 状态用一个 7px 圆点 + 一圈同色低透明光晕，不用色块横幅

## Don't

- 不要第二个强调色。橙色一旦超过三处，屏幕就没有焦点了
- 不要给卡片加边框来"分区"——明度已经分好了，边框只是收边
- 不要 mono 大写小标、不要 ⟨ ⟩ 图签框、不要把正文压到 13px
- 不要把输入框做成比地还暗的凹槽——它是灯，不是坑
