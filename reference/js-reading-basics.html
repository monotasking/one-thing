先分清语言和环境

JavaScript / JS：语言。Node.js：运行 JS 的环境，提供文件、网络等能力。浏览器：也能运行 JS，并有操作网页等能力。语法可以相同，可用功能取决于环境。Node.js 官方介绍

TypeScript / TS：在 JavaScript 基础上增加类型检查等能力。项目里的 .ts 文件会出现类型说明。比如 text: string 表示 text 应是字符串，不是发送或读取数据的动作。TypeScript 官方手册

变量、文字和列表

写法读法
let text = "你好";创建变量 text，先让它记住“你好”；以后可以重新赋值。
const output = [];让 output 指向一个空数组。数组是有顺序的列表；const 限制把 output 重新赋给别的值。
output.push("你好");调用数组的 push 方法，在末尾加一项。const 数组仍然可以增添元素。
"你好" / ""文字数据称为字符串；后者是不含字符的空字符串。
=在这些语句中表示赋值：让左侧保存右侧的值。不是比较两边是否相等。
// 说明注释，写给读代码的人看，不作为这行程序动作执行。

依据：MDN const、MDN Array.push。

函数与参数

function show(text) {
  output.push(text);
}
show("你好");

函数：这段名为 show 的可调用代码。参数：函数定义中接收输入的名字 text。实参：调用时实际传入的值“你好”。日常交流常把两者统称参数，读代码时区分“接收名字”和“传入值”即可。

写法对应动作
function show(text) { ... }定义函数。这里的括号是定义语法；函数体还没有因此执行。
show取到函数本身。此处没有调用 show。
show("你好")调用 show，传入“你好”。
run(show)调用 run，把函数 show 作为输入交给它。
bus.on("text", show)从对象 bus 取出 on 方法并调用；两个输入由逗号分开。

返回值：函数调用结束时交回的值。可用 return 指定；没有显式返回值时通常得到 undefined。所以“传入 show”和“调用 show 后传入它的结果”是两件事。

依据：MDN Functions。函数名、参数名都是程序员取的名字，不是因为叫 callback 才具有特殊语法。

回调：把函数交给别人调用

function run(callback) {
  callback("你好");
}
run(show);

run 接收了 show，内部用 callback 这个名字调用它。这里 show 就承担回调的角色。回调可以立即执行，也可以稍后执行；要看接收它的函数如何实现。MDN 回调定义
