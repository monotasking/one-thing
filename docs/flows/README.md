# 调用地图

每张地图描述一条主流程:从入口走到出口,每一步在哪个文件、哪个函数,是在**干活**还是只是**一层壳**。

读代码前先看地图,拿着地图打断点对照(调试方法见 [`../debugging.md`](../debugging.md))。

| 流程 | 地图 |
|---|---|
| 发送一条消息(到调用模型,再到回复上屏) | [send-message.md](send-message.md) |

## 写法约定

- **用函数名定位,不写行号。** 行号一改就漂,函数名可以直接搜。
- 每一步标角色:
  - **干活**:这一步有真正的业务逻辑;
  - **壳**:只是转交、包装、换形状,第一遍读可以跳过;
  - **查表**:按字符串或名字找下一步,跳转到定义过不去,地图里写明去哪里找。
- 旁支(失败重试、兜底分支、特殊场景)单独列出,标明正常情况下为什么走不到。
- **改了主流程的代码,同一个提交里更新对应的地图。**
