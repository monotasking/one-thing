# `forks:<域文件> <n>` —— `packages/backend/rpc/domains/*.ts` 里读了几次派发上下文的
#   `transport`(注释与字符串先剥掉;认 context/ctx/dispatchContext/rpcContext 四种形参名)。
#   **不认** `request.config?.transport === 'stdio'` 那种:它问的是 MCP server 用哪种传输起,
#   与派发上下文无关。任一文件高于这里的数、或出现这里没有的域文件 → 红;
#   文件从表里消失 = 那个域治愈了(降到 0),是 improvement。
#
# `ipcMain:apps/desktop-react/electron <n>` —— 新壳主进程手写的 IPC 通道条数
#   (`ipcMain.handle(` + `ipcMain.on(`)。今天只有 `host:connection` 一条:
#   渲染层其余全走 HTTP/SSE(CLAUDE.md「Process model」的二进程图)。
