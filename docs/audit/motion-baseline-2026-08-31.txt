# 两条规矩(法条与 --dur 族的三类分法写在 apps/desktop-react/src/styles/motion.css 的文件头):
#   ① @keyframes 只许住在 src/styles/motion.css —— 全仓唯一的动效产地,组件只引名;
#   ② transition / animation 的时长只许 var(--dur-*),不许字面 ms / s。

# 比对的键是「文件 + 违例种类 + 名字」,**不含行号** —— 在一条既有违例上面加一行注释
# 不该让它"变成新的"。同 squeeze-gate 的做法,理由一样。
