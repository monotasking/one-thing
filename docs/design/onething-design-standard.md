# onething — Design Standard（草案 v0.1 · 2026-08-16）

> 格式对齐 Refero Styles / Claude Design 的 style reference（Notion / Cursor / xAI / GIC / Monad 同款结构）。
> 每条值后带标记：**[定]** = 用户已拍板 · **[拟]** = 我的提案，等拍板 · **[空]** = 还没答案。
> 本文是**先于渲染**的标准：不再"渲一版看感觉"，而是标准定了再照标准渲。渲染出来的每张图都要能逐条回指到这里。

**Theme:** 跟随系统（light / dark 各一套值）[定]

## 0. 一句话与一段话

**Mood（一句）**：[空] —— 这句话是整套系统的种子，等下面的签名承诺定了再写；写不出这一句，说明系统还没有主意。

**Description（一段）**：[拟] onething 是一张放着三块面板的工作台：会话、正在做的事、手边的资料。窗口的地是一层有色的底，三块面板浮在上面，靠空隙而不是线分开；面板里的每张卡再高一档。一屏只有一件事被完整照亮，一处填色的按钮，一枚有含义的强调色。字只用无衬线，标题靠大小和字距而不是字重立起来；界面说人话，机器的话只出现在工具卡里。

## 1. 签名承诺（Signature Commitments）—— 识别度的来源

参照四份 refero 规范的共同点：每套都有 3–5 条**硬承诺**（Cursor：4px 到处用 + 标题字重 400 + 橙只做文字色 + 不用纯白纯黑；xAI：黑色丸形按钮 + 全屏单色 + 只靠奶油色分层不投影；GIC：绿调墨线 + 无填色按钮；Monad：mono 当正文 + 40px 卡 + 只一枚蓝）。**没有承诺的系统只会产出中位数，这正是"每个元素都像 AI 生成"的原因。** 以下是 onething 的候选承诺，需要拍板保留哪几条：

| # | 承诺 | 状态 | 说明 |
|---|---|---|---|
| S1 | **地是通道**：三块面板浮在有色的地上，面板之间与窗口边留空隙 | [拟]（力度待定） | 08-16 用户先说"要面板、要 margin"，后又说"分割线也可以做得很好看"——**分割线不再是禁令**：面板+空隙与 1px 线都是合法分区手段，按场合选 |
| S2 | **一处填色**：一屏只有一个填充强调块（发送）；其余动作全部软底或纯文字 | [拟] | "一次只做一件事"的按钮层表达 |
| S3 | **无彩色按钮**：主按钮用墨色（近黑/近白）填充，强调色**只**给选中、焦点、链接与助手标记 | [拟] | 直接对治"蓝按钮 = AI 味"；xAI/Cursor 同法 |
| S4 | **色阶承担层级**：地→面板→卡→嵌套四档纯靠明度分开，内容面零阴影；阴影只给离开平面的浮层 | [定] | 08-16 拍板"层级靠颜色不靠阴影" |
| S5 | **工作痕迹卡**：agent 每次工具调用都是一张有标题、有结果、有可执行动作的卡；mono 只在它内部出现 | [拟] | onething 独有的内容类型，别家系统没有 |
| S6 | **标题不加粗**：标题靠字号（≥2× 正文）与负字距立层级，字重 ≤ 500 | [拟] | 避开 Inter 700 的默认味；Cursor/GIC/Monad 同法 |
| S7 | **只用无衬线** | [定] | 08-16 拍板 |
| S8 | **一次只做一件事**：焦点区域完整对比，其余区域退一档 | [定]（原则）/ [拟]（力度） | 上一版"退后"力度弱到看不见，力度待定 |

## 2. Tokens — Colors [拟]

**默认档换成冷中性清爽色**（用户 08-16："Flexoki 暖调也难受"，方向"更清爽锐利"）。主题系统机制与 18 套皮保留，Flexoki 降为可选主题之一。以下为默认档，两列 = light / dark。

| Name | Light | Dark | Token | Role |
|---|---|---|---|---|
| Ground 地 | `#E9EBEE` | `#0F1012` | `--surface-ground` | 窗口的地；三块面板之间露出的通道 |
| Panel 面板 | `#FFFFFF` | `#1A1B1E` | `--surface-panel` | 侧栏 / 会话 / 工作台三块面板本体 |
| Card 卡 | `#F4F5F7` | `#232529` | `--surface-card` | 面板里的卡：输入框、工具卡、设置分节、选中行 |
| Nest 嵌套 | `#ECEEF1` | `#2C2E33` | `--surface-nest` | 卡里的行 / 控件底 |
| Overlay 浮层 | `#FFFFFF` + 阴影 | `#2C2E33` + 阴影 | `--surface-overlay` | 菜单、popover、对话框、toast —— 唯一允许阴影的一层 |
| Ink 墨 | `#111318` | `#F2F3F5` | `--ink-1` | 正文、标题 |
| Ink-2 | `#3D4250` | `#C6C9D0` | `--ink-2` | 次要正文 |
| Ink-3 | `#6B7180` | `#8B909B` | `--ink-3` | 元信息、占位 |
| Ink-4 | `#9AA0AC` | `#5C6169` | `--ink-4` | 禁用、最弱 |
| Line 线 | `#E2E4E8` | `#2E3137` | `--line` | 只用于卡内行间；**不做区域分割** |
| Action 墨按钮 | `#111318` | `#F2F3F5` | `--action-fill` | 主按钮填充（S3）；文字反色 |
| Accent 强调 | [空] | [空] | `--accent` | 选中、焦点、链接、助手标记；候选：蓝 `#2563EB`/`#5B8DEF`、青 `#0F8B8D`/`#3FB6B8`；**不给按钮** |
| Success / Warning / Danger | `#16A34A` / `#D97706` / `#DC2626` | `#4ADE80` / `#FBBF24` / `#F87171` | `--status-*` | 只做状态语义，形态是软底小丸（底 = 色 12% 混白/黑） |

Do：地永远不是白；面板永远是最亮（light）/次暗（dark）的那一档；卡比面板低一档 —— 三档相邻明度差 ≥ 4 L。
Don't：不用纯 `#000`；不把强调色铺成面；不用渐变、发光。

## 3. Tokens — Typography

| 族 | 字体 | 状态 | 角色 |
|---|---|---|---|
| Sans（拉丁） | [拟] Geist / Instrument Sans / 继续 Public Sans 三选一 | [空] | UI 与正文；**这是识别度第二大杠杆**（Cursor 的 CursorGothic、xAI 的 universalSans 都是自家脸），值得单独拍板 |
| Sans（中文） | 思源黑体 / PingFang SC 回退 | [定] | 与拉丁配对，字重对齐 |
| Mono | Geist Mono / JetBrains Mono | [拟] | **只在工具卡内部**：路径、diff、耗时 |
| Serif | 无 | [定] | — |

### Type Scale [拟]（正文 15 起，比率 ≈ 1.2；≤ 8 档）

| Role | Size | LH | Tracking | Weight | 用途 |
|---|---|---|---|---|---|
| caption | 12 | 1.4 | +0.005em | 400 | 时间戳、元信息 |
| label | 13 | 1.4 | 0 | 500 | 分组标题、按钮 |
| body | 15 | 1.6 | 0 | 400 | 正文、消息 |
| body-lg | 16 | 1.6 | 0 | 400 | 会话正文（可选档） |
| h3 | 20 | 1.3 | -0.01em | 500 | 卡标题 |
| h2 | 26 | 1.25 | -0.015em | 500 | 面板标题 |
| h1 | 34 | 1.15 | -0.02em | 500 | 会话标题 |
| display | 44 | 1.1 | -0.025em | 500 | 空态 / 首启，会话内不用 |

规则：标题字重 ≤ 500（S6）；标题 ≥ 2× 正文；全系统 ≤ 8 种字号。

## 4. Tokens — Spacing & Shape

**Base unit** 4px [定] · **Density** comfortable（面板内 16、卡内 12–16、面板间 12）[拟] · **Reading measure** 640px [拟]

### Spacing Scale [定]（现有 `--space-*` 保留：4 8 12 16 20 24 32 40 48）

### Border Radius [拟] —— 参照 Cursor 的"一表到底"，全系统只许三档 + 丸

| Element | Value |
|---|---|
| 面板（侧栏 / 会话 / 工作台） | 12px |
| 卡（工具卡、输入框、设置分节、对话框） | 8px |
| 控件（按钮、输入、chip、分段） | 6px |
| 丸（状态小丸、头像） | 9999px |

现有 `--radius-xs/sm/md/lg/xl`（3/6/10/16/24）收敛为 `--radius-panel/card/control/full`。**禁止**在同一面上混用 4 与 16。

### Elevation [定]（S4）—— 按用途命名，不按大小

| 用途 | 处理 |
|---|---|
| 面板 / 卡 / 嵌套 / 输入框 | **无阴影**，纯色阶 |
| 菜单 / popover / 下拉 | `--shadow-overlay`：`0 8px 24px rgba(0,0,0,.12)`（dark `.45`）+ 1px line |
| 对话框 | `--shadow-modal`：`0 16px 48px rgba(0,0,0,.18)`（dark `.6`） |
| toast | 同 overlay |
| 拖拽中的对象 | 同 modal |

现有 10 档 `--shadow-*`（xs…floating/paper/glow）收敛为上述 2 档；`glow` 全部删除。

### Motion [定]（保留现状）：120ms `cubic-bezier(.4,0,.2,1)`；浮层出现 160ms；无弹跳。

## 5. Surfaces（层级表）[定]

| Level | Name | 住户 | 线索 |
|---|---|---|---|
| 0 | Ground 地 | 窗口本身、面板之间的通道 | 最低明度（light）/ 最深（dark） |
| 1 | Panel 面板 | 侧栏、会话、工作台 —— **永远三块、永远有 12px 通道** | 高一档 + 12px 圆角 |
| 2 | Card 卡 | 输入框、工具卡、设置分节、选中会话行、分段控件 | 比面板低一档（light）/ 高一档（dark），8px 圆角，有内边距 |
| 3 | Nest 嵌套 | 卡内的行、chip、步进器 | 再一档 |
| 4 | Overlay 浮层 | 菜单、popover、对话框、toast | **唯一带阴影**的层 |

禁令：同层不得既凹又凸；输入框永远不低于卡层。区域之间可以画线，但线只是**辅助**（≤ 8% 墨），层级主体仍靠色阶与围合。

## 7. Do / Don't [拟]

**Do**
- 分区用色阶 + 围合，线只做辅助（≤ 8% 墨）
- 一屏一处填色，且是墨色；强调色只给选中 / 焦点 / 链接 / 助手
- 层级只靠色阶；阴影只在浮层
- 标题字重 ≤ 500，靠字号与负字距立起来；正文 ≥ 15
- 分组标题、按钮、状态全部说人话；mono 只在工具卡里
- 圆角只用 12 / 8 / 6 / 丸

**Don't**
- 不用 1px 线当唯一的分区手段（线可以有，但不能是层级的全部）
- 不用彩色填充按钮；不用蓝色当"默认强调"而不加思考
- 不给内容卡加阴影或发光环；不用渐变
- 不用 mono 大写做标签；不用 ⟨ ⟩ 之类的符号装置
- 不在同一面混两种圆角档
- 不用 10–13px 当正文
