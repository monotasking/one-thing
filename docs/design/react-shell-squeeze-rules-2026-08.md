# 抗挤压四律(React 壳,2026-08-30)

窄下来的时候,界面该怎么排。四条法,一条真机门,一条静态棘轮。

适用范围:`apps/desktop-react` 的全部界面。壳的三种形态(舞台 / 浮窗 / 钉边架子)
里,宽度是**用户随手拖出来的连续值** —— 架子厚度下限 240px、浮窗下限 280px,
上不封顶。所以「窄了怎么办」不是一个边角情形,是每天都会走到的常态路径。

## 起因:一段视频里的三处病

08-30 用户把会话总览钉在右边,把架子从 ~420px 拖到 260px,录了一段。三处病:

1. **组头行文字重叠。** 长组名(agent-dm 那种 uuid 目录)在窄档里折行,折下来的
   第二行压住右端的「N sessions」计数徽。真机量到的最坏一格是 69.6×16.5px 的
   重叠面积 —— 不是"挤"，是**字压着字**。
2. **首个组头被面板上缘裁切。** 用户读作「粘性组头被裁切」,而真机勘察给出的
   是另一句话:**组头压根不粘**。改之前全仓一条 `position: sticky` 都没有,
   组头就是普通流内元素;`.inner` 的 `padding-top` 又是 0,首个组头贴死滚动
   容器的裁剪边(实测 scrollTop=0 时 headTop=0,滚 12px 就被削掉 12px)。
   于是往下滚一点点,组头就被上缘切掉一条、再滚就整个没了。
3. **卡在窄档大而空。** 宽档的卡形被原样塞进 260px,内边距、行距、两行预览
   一格没变,于是一屏只放得下三张卡,每张卡里还都是空白。

第 1 处是这四律的**范例反例**,下面每一条都拿它当尺子。

### 反例解剖:组头那一行

改之前那一行是这样的(节选):

```css
.groupHead  { display: flex; align-items: center; gap: 12px; height: 40px; }
.groupToggle{ flex: 1; min-width: 0; }        /* 里面装 caret + 组名 + 路径副名 */
.groupName  { font-size: 14px; font-weight: 700; }   /* ← 病灶 */
.groupPath  { flex: 1; min-width: 0; …ellipsis }
.count      { flex: none; }                    /* 「N sessions」 */
```

`.groupName` 这条规则**只写了字体**。于是它拿的是 flex 项的两个默认值:
`min-width: auto`(不许缩到 min-content 以下)与 `white-space: normal`(可以换行)。
两个默认值合起来的意思是:「这块文字**既不肯变窄,也不肯只占一行**」。

窄下来之后它有两种死法,组名的形状决定走哪一种:

- 名字里有连字符(`3f2a9c7e-8b41-4d6a-9f02-7c1e5b8d4a63`)→ CSS 允许在连字符后
  断行 → **折行**。行高涨到两行,而 `.groupHead` 是写死的 40px,于是第二行溢出
  行外,把下面那张卡的标题压住(实测 53.3×18.0px)。
- 名字里没有断行机会(`a1b2c3d4e5f60718293a4b5c6d7e8f90`)→ 一行到底 →
  **整条溢出**,把右端的计数徽压住(实测 69.6×16.5px)。

两种死法同一个病根:**一行里有一个不肯弯腰的文本件**。

## 律一 · 一行恰有一个弯腰件

> 一行里,承担「吸收剩余空间」(`flex-grow: 1`)的件**只能有一个**;
> 任何可伸缩的文本件必须**同时**具备 `min-width: 0`(column flex 里是
> `min-height: 0`)与一条截断策略(`text-overflow: ellipsis` 或 `line-clamp`);
> 不承担伸缩的件一律 `flex: none` 并有确定宽度。

为什么是「同时」:两句话各解一把锁,少一把都开不了门。`min-width: 0` 解的是
**能不能缩**,截断策略解的是**缩了之后怎么收场**。只给 `min-width: 0` 而不给
省略号,文字会被硬切在半个字上;只给省略号而不给 `min-width: 0`,那个盒子
根本缩不下来,省略号永远不出现。

组头那一行修完是:

```css
.groupName { flex: 0 1 auto; min-width: 0; white-space: nowrap;
             overflow: hidden; text-overflow: ellipsis; }   /* 可缩,不抢空间 */
.groupPath { flex: 1 1 auto; min-width: 0; …ellipsis }       /* 唯一吸空间的角色 */
.enter, .plus { flex: none; }                                /* 入口不弯腰 */
```

`flex: 0 1 auto` 与 `flex: 1 1 auto` 的分工,顺带定下了**谁先让**:主名不去抢
剩余空间,副名去抢;挤起来两个都缩,而按 flex 的比例分配规则,基准宽度大的
(长路径)让得多 —— 于是「主名比副名晚一步消失」是排出来的,不是硬编码的。

## 律二 · 结构行里的文本永不换行,只截断

> 结构行(组头、檐、工具行、列表行、tab、状态条)里的文本一律
> `white-space: nowrap` + 截断。换行属于**正文区**(消息、预览、说明段),
> 那里高度本来就跟着内容走。

判据不是「这段字长不长」,是**这一行的高度是不是被别的东西定住的**。结构行的
高度是版式的一部分(`--list-row-h` 40px、`--row-h` 28px),它不跟着内容涨;
一旦里面的文字换了行,内容高度就超过了行高,超出去的那部分必然落在别人身上。
上面那个 `.groupName` 折行压住下一张卡的标题,就是这条的教科书演示。

正文区反过来:`.summary` 允许两行(`line-clamp: 2`),因为卡的高度是
`min-height` 不是 `height` —— 它准备好为内容长高。

## 律三 · 覆盖内容必须有布局预留

> 任何盖在内容上面的元素,都要在布局里**先把位置空出来**。
> 允许不预留的只有三族浮层:tooltip / menu / toast —— 它们生命周期短、
> 由一次明确手势唤起、并且挂在 portal 上不属于这棵布局树。
>
> 粘性头(`position: sticky`)是**另一种预留**,不是例外:它的预留不在布局里,
> 在**滚动坐标系**里 —— 滚动容器必须声明 `scroll-padding-top` ≥ 粘性头高度。
> 没有那一句,`scrollIntoView` 会把目标停在粘性头底下:焦点环在,东西看不见。

「动作住檐 / 住缘」那条既有拍板就是这条律的一个实例:卡片右上角的 QuickLook
预览眼是绝对定位的,而 `.head` 常驻一条 `padding-right` 把那块地方空着 ——
所以眼睛淡入的时候,一像素都不会挪动标题(无位移原则),而且窄到 240px 时
它压住的仍然是留给它的那块空白,不是标题的最后一个字。

组头右端新的幽灵「›」入口同样:它是 `flex: none` 的常驻项,只动 `opacity`。
「hover 才显形」是可见性,不是存在性 —— 一个 hover 时才被插进 DOM 的按钮,
会把整行推一下,那正是这条律要防的。

## 律四 · 每个组件在自己声明的最小宽度下零重叠

> 组件要声明自己能活到多窄(会话卡是 `--card-min-w: 260px`,架子是
> `SHELF_MIN_THICKNESS: 240px`)。在那个宽度上,它必须**零重叠**。
> 变窄的次序永远是:**先截断 → 再有序降元素(显 → 隐)**;永不重叠。

「有序降元素」是说,降的次序要事先想好、写在一处,而不是让浏览器随机决定
谁溢出。会话总览的降序是:

| 容器宽度 | 组头 | 会话卡 |
| --- | --- | --- |
| > 560px | 组名 + 路径副名 + 入口 | 标题 / 预览两行 / 摘要 / 模型徽 + 时间 |
| 560 → 420px | 同上(顶栏改为两行) | 同上 |
| ≤ 420px(**N2 压缩形**) | 路径副名**降掉** | 预览钳到一行、卡矮下去、模型徽设硬顶 |

只有一个阈值(420px)。**不做更窄的第二档** —— 两个阈值就是两份要维护的真相,
而 240 与 420 之间该做的事,连续量已经用 `clamp()` 走完了。

### 切档必须是布局连续的

拖架子厚度是**逐帧路径**(EdgeShelf 拖拽期间逐帧写本地 state),tab 切换那一批
的判例在这里同样成立:这条路上不许出现整棵树重建,也不许出现 JS 驱动的形变。
所以切档的做法定死三条:

1. **两档共用同一套 DOM。** 不换组件、不重挂 —— 滚动位置与选中态天然保住,
   因为它们从来没被销毁过。禁 FLIP,禁 JS 驱动形变。
2. **连续量用 `clamp()` 随容器插值。** 内边距、行距、组名字号都是这一类。
   写法上有一条硬约束:这些 `clamp()` 在容器 = 420px 处**恰好等于宽档的老值**
   (`--squeeze-ramp = 420px - 100cqi`,≥420 时为负 → clamp 取上界),
   于是阈值那一点没有台阶,而 >420 的宽档逐像素与从前相同。
3. **离散量各自软化,并且错峰。** 预览 2 行 → 1 行、路径显 → 隐、模型徽收窄,
   这三件事没法插值,只能在阈值处翻。各配一次 120ms 的 opacity / max-height /
   min-height 过渡,并用 `--squeeze-stagger-1/2/3`(0 / 40 / 80ms)岔开 ——
   三件事挤在同一帧一起跳,看起来就是一次「闪」。

几何全部在 `apps/desktop-react/src/styles/tokens.css` 的「抗挤压 / 窄形 N2」一节。

## 执法

| | 查什么 | 代价 | 挂在哪 |
| --- | --- | --- | --- |
| `npm run squeeze-check` | 打全表 | 毫秒 | 手动 |
| `npm run squeeze-gate` | 律一的静态近似,棘轮 | 毫秒 | `verify`(lint 之后) |
| `npm run gate:squeeze` | 律四,真机五档零重叠 | 一次 Electron + core | `verify`(真机门最后一条) |

**静态那条抓不到什么,要说在前面。** `squeeze-check` 只查一句:声明块里出现了
`flex: 1` / `flex-grow`,同一个块里却没有 `min-width` / `min-height`。它抓的是
「能拉伸却不能收缩」这一类高发写法 —— 但**它抓不到本批那个组头病灶**:
`.groupName` 改之前压根没写 `flex`,静态规则无从下手。层叠、方向、截断策略在不在,
它也都不看。所以它是近似,不是律一的判定;真正的判据在真机门那一侧。

**真机门查的是排版本身。** `gate-squeeze.mjs` 把会话总览钉到右架子,厚度依次拖到
240 / 300 / 360 / 420 / 560,每一档滚一遍,把架子里**自己画内容的盒子**两两求交
(祖孙对除外,容差 1px)。两个细节值得记下来,都是首跑踩出来的:

- 口径不是立项时写的「兄弟两两求交」。报障那一例里溢出的 `.groupName` 是
  `.groupToggle` 的孩子,被压住的 `.count` 是 `.groupToggle` 的兄弟 —— 两者是
  **叔侄**。只比兄弟的话,这条门在修前是绿的,而屏幕上字压着字。
- 比的是**看得见的那一块**,不是几何矩形。一个滚上去的卡,它的
  `getBoundingClientRect()` 仍停在滚动容器上缘之外,拿它去比会和顶栏"相交",
  而屏幕上那里什么都没有。所以每个盒子都要沿祖先链逐层与 `overflow` 不为
  `visible` 的祖先求交,裁完宽或高 ≤ 0 就是「屏幕上根本没有它」。

白名单(`ALLOWED_OVERLAP`)是律三的例外表,加一条要写一句理由。默认**不**整类
豁免绝对定位 —— 绝对定位恰恰是「覆盖」最常见的实现方式,整类放行等于把律三的
执法面挖空。

粘性头有一条**带条件的**豁免,条件由门自己查:两个盒子的「粘性宿主」不同
(一个在粘性头里、另一个从它底下滚过去)才跳过;**同一个粘性头之内照查不误** ——
组名压住计数徽正是同一个粘性头里的两件,一格都不许放。而这条豁免的代价是门里
多出的一步 `checkStickyReservation`:每个粘性头所在的滚动容器,必须声明
`scroll-padding-top` 且不小于粘性头的高度,否则红。豁免与它的预留是一对,
不许只拿前一半。

### 修法(2026-08-30 落地)

| 病 | 根因 | 修法 |
| --- | --- | --- |
| 组头文字重叠 | `.groupName` 只写了字体,吃着 flex 项的两个默认值(`min-width: auto` + `white-space: normal`) | `flex: 0 1 auto` + `min-width: 0` + 单行省略号;副名改 `flex: 1 1 auto` 当唯一吸空间的角色;右端入口一律 `flex: none` |
| 首个组头被上缘裁切 | 组头不粘,且贴死滚动容器裁剪边 | `.groupHead` 粘顶(`--surface-1` 底,三种形态的 body 都是它),`.scroll` 配 `scroll-padding-top: var(--list-row-h)` |
| 窄档大而空 | 宽档卡形原样塞进窄容器 | N2 压缩形:连续量走 `*-fluid` clamp,离散量(预览钳一行 / 卡矮下去 / 模型徽设顶 / 路径副名降掉)各配一次 120ms 软化并错峰 |

顺带执行的一条拍板:**tab / 列表 / 分组头一律不带个数**。组头上那颗写着
「N sessions」的按钮,数字删掉、入口留下 —— 换成右端的幽灵「›」,与卡片右上角
那只 QuickLook 眼睛同一条配方(常驻占位、只动 opacity)。
