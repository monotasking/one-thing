# 分层秩序 / Stratified Order

一种以**层**为唯一母题的视觉语言。它不解释系统，它呈现系统的重力方向。全画由一个动作构成：把不可见的结构变成可见的秩序，然后极力克制，不去多说一个字。

**空间与形**：一切由矩形承担。没有圆角、没有阴影、没有渐变——形状只表达一件事：这一块与那一块的边界在哪里。层的宽度一致，高度一致，间距一致；重复本身即是论证。层与层之间只留一道细线，那道线就是关系本身。左侧一条贯穿全高的竖线加一个向下的箭头，把「只准向下」这句规矩画成重力，而不是写成句子。

**色与材**：纸色打底，五色为限。每层一条四像素的色带，色即身份——绿属装配，蓝属产品，墨属骨架，赭属宿主。色彩不装饰，它承担索引功能：读者凭色带定位，不凭文字。其余全部灰阶，只有线与字。整幅的彩色面积不超过百分之三——正因如此，那几条色带才有分量。这种克制是反复称量出来的，多一格色都算失手。

**尺度与节律**：字分三级，绝不越级。层名最大，角色说明次之，包名最小并以等宽字呈现——它是坐标，不是句子。三级之间的字号差是刻意拉开的：它让眼睛在扫过的一瞬就知道该先读哪一行。留白不是剩余空间，而是被安排出来的呼吸：每一层四周的空白按同一把尺子量过，四边等距，分毫不差。

**构图与平衡**：主栏承载四层，占去宽度三分之二，稳如承重墙。右侧一条窄栏承载配件与一次请求的两个方向——它答的是「谁在旁边」和「东西怎么走」，是主栏的注解而非并列。底部一条横向长条收纳外部世界，压住整个画面，使重心落地。主栏密，侧栏疏，底部舒展——疏密关系是被反复推敲过的，不是排版的结果，是判断的结果。

**视觉层级**：读者应当先看见四层的堆叠与那道向下的箭头，再看见色带，最后才读字。若一幅图需要逐字读完才明白，它就已经失败了。因此文字只保留三类：层名、包路径、角色的半句话。「半句话」是有意的——它给出方向，不给结论，留出让读者自己去源码里走下去的余地。

**工艺**：这是一件要用数月之功才配得上的作品，最终必须看起来像出于领域顶尖之手。每一条线的端点对齐到像素，每一处间距来自同一套模数，每一个字的字重都经过权衡。任何一处重叠、任何一次溢出、任何一行字的基线不齐，都算整幅作废。完成后要再看一遍——不是加东西，而是把已有的东西再收紧一分：让色带更短一分，让留白再宽一分，让那半句话再删掉两个字。克制到底，方成器物。
