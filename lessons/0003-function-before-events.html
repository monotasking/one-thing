02

先读懂一个小函数

let screen = "";

function show(text) {
  screen = text;
}

函数是一段有名字、可以被调用的代码。这里我们给它起名 show；这个名字是示例自己取的，不是 JS 自带的命令。

这一小段按人话读
let screen = "";创建一个叫 screen 的变量，让它先记住空文字。变量是用名字保存、读取值的方式。
function show(text)定义名为 show 的函数；它接收的输入在函数内部叫 text。text 是参数。
{ ... }包住这个函数实际要做的步骤，称为函数体。
screen = text;把 text 的值赋给 screen。这里的等号表示赋值。

"" 是空字符串，"你好" 是包含两个字的字符串。字符串就是文字数据。这里的 screen 只是教学变量；给它赋值本身不会自动改变真实网页。

把函数定义出来，还没有执行函数体。当执行 show("你好") 时，输入“你好”交给参数 text，函数体才把它放进 screen。MDN：定义与调用

03

不加括号，拿到的是函数本身

在函数定义之外看到发生了什么
show取到 show 这个函数本身，没有在这里调用它。
show("你好")调用 show，把文字“你好”作为输入交给它。
run(show)调用的是 run；把 show 这个函数作为输入交给 run。

函数本身也可以当作一个值传递。就像把文字传给 show 一样，也可以把函数传给 run。至于 run 收到后会不会调用它，要进入 run 的代码看。

不要只凭“看到括号”判断执行：function show(text) 是定义语法；show("你好") 才是这里讨论的调用语法。

04

逐步读：别人如何调用这个函数

接着定义一个新函数 run，它接收的输入叫 callback。callback 只是参数名；在这次调用中，它接到的是 show 这个函数。

从定义，到实际执行逐步阅读 · 教学代码
定义写好做法
传入交给 run
调用进入 show
赋值文字改变

第 1 步 / 准备 show

先定义要做什么

let screen = "";
function show(text) {
  screen = text;
}

已经有了一个函数，但还没有人调用它。函数体里的赋值此刻不执行。

screen 的值空字符串：""

第 2 步 / 准备 run

再定义一个会调用输入函数的函数

function run(callback) {
  callback("你好");
}

run 的做法是：拿到 callback 后，用“你好”调用它。这里仍然只是在定义 run，里面这行还没有执行。

screen 的值仍是空字符串：""

第 3 步 / 调用 run

把 show 本身交给 run

run(show);

这对括号属于 run：现在进入 run。参数 callback 接到的就是 show 这个函数；还没执行到 run 里面的调用语句。

参数对应关系run 内部的 callback 指向 show；screen 仍是 ""。

第 4 步 / 执行 run 里面的语句

callback("你好") 调用了 show

callback("你好");

因为 callback 接到的是 show，这里就是通过 callback 来调用那个 show 函数。输入“你好”传到了 show 的参数 text。

参数对应关系show 内部的 text 现在是 "你好"。

第 5 步 / 执行 show 里面的语句

screen 终于有了文字

screen = text;

赋值完成。show 结束后回到 run，run 也结束。本例中的回调是当场调用的，没有定时器或网络等待。

screen 的值"你好"
1 / 5

像 show 这样，传给另一个函数、供它调用的函数，就叫回调函数。回调可以当场被调用，也可以在以后被调用；“回调”这个词不规定等待多久。MDN：Callback function

合上上面的步骤：run(show) 直接调用的是谁？

先判断，再点选；不需要记术语，先看括号属于谁。

05

这样就能接回事件订阅了

bus.on("text", show);

bus 是一个对象：你可以先把对象看成装着有名字的数据和功能的集合。点号 . 表示取出它的某一项。on 是它的一项函数功能，这种属于对象的函数也叫方法。

这行调用 bus.on，给它两个输入：事件名 "text" 和函数 show。逗号把两个输入分开。

前面 run 的做法是立即调用收到的函数；这里 on 的做法是登记收到的函数，供事件触发时调用。这个差别来自各自的实现。EventEmitter 的 on / emit 说明

在 bus.on("text", show) 中，show 这一项传过去的是什么？

这是理解“先登记，后调用”的关键区别。
